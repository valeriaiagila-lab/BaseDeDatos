## 🎯 Objetivo del repositorio

Organizar y documentar las actividades académicas de la asignatura, aplicando los conocimientos adquiridos sobre el diseño, la implementación y la administración de bases de datos, así como el procesamiento y análisis de datos.

## 📚 Contenido de la asignatura

### 1. Bases de datos relacionales
- Fundamentos de bases de datos.
- Modelo entidad-relación.
- Modelo relacional.
- Álgebra relacional.
- Lenguaje SQL.
- Administración y optimización de bases de datos.
- Copias de seguridad y recuperación.
- Transacciones y propiedades ACID.

### 2. Bases de datos NoSQL
- Fundamentos y características de las bases de datos NoSQL.
- Bases de datos clave-valor.
- Bases de datos documentales.
- Bases de datos columnares.
- Bases de datos orientadas a grafos.
- Bases de datos distribuidas y replicación.
- Bases de datos en la nube.

### 3. Fundamentos de ciencia de datos
- Limpieza y preparación de datos.
- Procesamiento de datos con Python.
- Análisis estadístico básico.
- Manipulación de datos con pandas y NumPy.
- Visualización de datos.
- Elaboración de gráficos y dashboards.
- Fundamentos de Big Data.
